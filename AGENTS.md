# Instructions for coding agents

Follow [CONTRIBUTING.md](CONTRIBUTING.md): it holds the project goal, the workflow and who owns what.
On top of that:

- After every `git pull`, read [QUESTIONS.md](QUESTIONS.md) and tell your human about anything open
  for them. Before every push, record the questions you raised, answers you found and state changes.
- Before writing code, run `gh issue list` and `gh pr list`. If an issue or PR already covers the
  work, stop and tell your human.
- Never start a training run without your human confirming the repo owner approved it.
- Never guess an unknown (a measurement, a version, a result). Write "unknown" and ask.
- Stay inside your side's paths (CONTRIBUTING.md § Ownership) unless the other side has acknowledged
  an issue for the change.
